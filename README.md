🌍 India Tourism – Explore Incredible India

A modern, responsive, and visually appealing Tourism & Travel Booking Website built using HTML, CSS, and JavaScript.
This project allows users to explore destinations, search hotels, view tourist attractions, check sample weather data, and access travel information through beautifully designed pages.

✨ Features


#🏠 Home Page

Beautiful hero section with iconic world landmarks

CTA button: Plan Your Journey

Gradient banner with smooth edges

Navigation bar with Home, Destinations, About, Contact, Sign In

#📸 Destinations Page

Explore popular destinations across India

Clean card layout with images

Responsive design for all screen sizes

#🔍 Search Results Page

Displays:

Hotels list

Tourist attractions

Weather card

Date & guest filter summary

“Grid / List” views for hotels

Beautiful pricing cards inspired by modern travel websites

#🏨 Hotel Details Page

Room details

Photos gallery

Pricing & offers

Highlights

Booking information

#🔐 Login Page

Modern gradient background

Email/password login

Google-style login button

“Create new account” option

#☎️ Contact Page

Inquiry form

Address, phone, and email details

Clean two-column responsive layout
